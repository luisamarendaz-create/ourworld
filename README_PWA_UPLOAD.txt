OurWorld — safe icon installation update

The included index.html has your existing Supabase PROJECT URL and PUBLIC PUBLISHABLE KEY configured so logging in will continue working. Do not publish passwords or Supabase secret/service_role keys.

1. Extract this ZIP.
2. Open https://github.com/luisamarendaz-create/ourworld
3. Add file > Upload files.
4. Select index.html, manifest.webmanifest, sw.js, apple-touch-icon.png, icon-192.png, icon-512.png, favicon-32x32.png and favicon-16x16.png. The original icon and this README are optional.
5. Commit changes. GitHub may show an overwrite/conflict for index.html: upload via the browser normally replaces the file in the new commit.
6. Actions > pages build and deployment: confirm green check.
7. Open https://luisamarendaz-create.github.io/ourworld/ and ensure sign-in still works.
8. On iPhone, remove any old Home Screen shortcut, reopen site in Safari, Share > Add to Home Screen > Add.

The existing app appearance and layout remain unchanged. This update affects only installation metadata and icons.
